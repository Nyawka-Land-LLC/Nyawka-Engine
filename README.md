## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Nyawka-Land-LLC/Nyawka-Engine.git
cd Nyawka-Engine
```

Build:

```bash
mvn clean package
```

Run:

```bash
java -jar target/nyawka_engine-*.jar
```
